## Brand & Style

This design system expresses a high-caliber, forward-thinking software engineering aesthetic tailored for Muhammad Kashif. It marries terminal precision with sleek, modern product polish. 

### Core Ethos
- **Technical Rigor & Innovation:** Evokes high performance, systems architecture, and modern full-stack velocity.
- **Atmospheric Immersion:** Utilizes deep celestial charcoals layered with glowing energetic cyan highlights, delivering a high-tech studio environment rather than a generic dark theme.
- **Tactile Modern Glass:** Combines ultra-subtle translucent glassmorphism surfaces, hairline cyan-tinted borders, and micro-glow accents to elevate digital craft.

### Visual Style
- **Dark Modern Glass & Code Utility:** Deep slate base layers contrasted with sharp typography, translucent panels, and vibrant electric status nodes.
- **Intended Emotional Response:** Confidence, technical competence, architectural clarity, and modern engineering craftsmanship.

## Colors

The palette is engineered around an immersive, low-noise dark space punctuated by hyper-focused luminescent accents.

### Palette Architecture
- **Primary (`#00E5FF` - Electric Cyan):** Used for focal interactive states, glowing status badges, active indicators, and high-impact micro-accents.
- **Secondary (`#3B82F6` - Tech Cobalt):** Anchors deep gradient fills, secondary interactive triggers, links, and code construct highlights.
- **Tertiary (`#10B981` - Emerald Node):** Reserved for "available for hire / active build" pulse points and success telemetry.
- **Neutral Canvas (`#0B0F17` to `#131B2E`):** Pure deep slate base with rich navy undertones to prevent display deadness and eliminate optical eye fatigue.

### Color Rules
- Maintain high contrast between monospace code elements, body copy, and container surfaces.
- Avoid using `#00E5FF` as solid large container backgrounds; reserve it strictly for hairline borders, radiant glows, key text labels, and actionable vectors.

## Typography

The type system blends the contemporary, geometric clarity of **Plus Jakarta Sans** for narrative flow with the structural authority of **JetBrains Mono** for metrics, metadata, and syntax.

### Hierarchy & Treatment
- **Display & Section Titles:** Tight tracking (`-0.02em` to `-0.03em`) on Plus Jakarta Sans creates a confident, modern product presence.
- **Technical Metadata & Tags:** `JetBrains Mono` handles tech stack chips, project timeframes, git commits, and shell commands with clean, tabular rhythm.
- **Readability Balance:** Body text is calibrated at `#94A3B8` (slate-400) against the charcoal background to achieve optimal readability without blinding luminance.

## Layout & Spacing

A 12-column responsive fluid grid structured inside a constrained viewport maximum (`1200px`) keeps portfolios dense, purposeful, and easy to parse.

### Breakpoints & Adaptation
- **Desktop (1024px+):** 12 columns, `1.5rem` gutter, `3rem` canvas margins. Asymmetrical card layouts (e.g., featured project spanning 7 columns, stack breakdown spanning 5).
- **Tablet (768px - 1023px):** 8 columns, `1.25rem` gutter, `2rem` canvas margins. Grid cards fold to 4-column balanced pairs.
- **Mobile (<768px):** 4 columns, `1rem` gutter, `1.25rem` outer margin. Full single-column reflow with persistent safe areas for mobile touch zones.

### Spatial Rhythm
- Apply `space-md` to internal card paddings to create breathable framing for code snippets and project imagery.
- Maintain a minimum vertical gap of `space-xl` between major portfolio sections (Hero, Featured Architectures, Work History, Core Stack).

## Elevation & Depth

Visual hierarchy relies on backdrop blur glassmorphism, surface luminance layering, and targeted cyan/cobalt optical glows.

### Surface System
- **Level 0 (Canvas Base):** Solid `#0B0F17`.
- **Level 1 (Card / Container Glass):** Background `rgba(19, 27, 46, 0.65)` layered over an 18px backdrop blur (`backdrop-filter: blur(18px)`). Framed by a 1px boundary stroke of `rgba(255, 255, 255, 0.08)`.
- **Level 2 (Hover & Elevated Modal):** Background `rgba(26, 38, 64, 0.8)` with a 1px cyan-tinted hairline border `rgba(0, 229, 255, 0.35)` and a subtle ambient drop shadow: `0 12px 32px -8px rgba(0, 0, 0, 0.6), 0 0 20px -4px rgba(0, 229, 255, 0.15)`.

### Atmospheric Glow Accents
- Ambient background radial gradients (e.g., `radial-gradient(circle at 50% 0%, rgba(0, 229, 255, 0.08) 0%, transparent 60%)`) sit behind hero credentials and featured case studies to provide soft, futuristic depth without interfering with content legibility.

## Shapes

The interface employs a balanced rounded geometric architecture. 

### Corner Radius System
- **Pills / Status Chips (`rounded-full`):** Used on status badges, tech stack tags, and compact call-to-actions to communicate interactive modularity.
- **Cards & Visual Containers (`rounded-xl` / 1.5rem):** Softens dense data cards, terminal previews, and project showcases.
- **Interactive Inputs & Nested Panels (`rounded-md` / 0.5rem):** Delivers clean structure to form controls and code blocks.

## Components

### Buttons
- **Primary CTA:** Gradient fill transitioning from `#00E5FF` to `#3B82F6` with bold slate-950 text (`#0B0F17`), fully rounded (`rounded-full`), padded `0.75rem 1.75rem`. On hover, applies an exterior bloom: `box-shadow: 0 0 24px rgba(0, 229, 255, 0.45)`.
- **Secondary / Glass CTA:** Background `rgba(255, 255, 255, 0.04)`, 1px border `rgba(255, 255, 255, 0.15)`, text `#F8FAFC`. On hover, border transitions to `rgba(0, 229, 255, 0.6)` with text `#00E5FF`.

### Status Indicators & Badges
- **Live Status Pill:** A pill container featuring a live animated radar dot. Background `rgba(16, 185, 129, 0.1)`, border `1px solid rgba(16, 185, 129, 0.3)`. Contains a pulsing emerald ping (`#10B981`) paired with `label-mono` text reading "AVAILABLE FOR ROLES" or "ACTIVE SPRINT".

### Tech Stack Pills & Tags
- Compact tags with `0.375rem 0.75rem` padding, `rounded-full` radius.
- Background: `rgba(255, 255, 255, 0.03)`, border: `1px solid rgba(255, 255, 255, 0.08)`.
- Text: JetBrains Mono `12px`, color `#94A3B8`.
- Interactive state: subtle scale up `1.03`, border shifts to `rgba(0, 229, 255, 0.4)`, font shifts to `#E2E8F0`.

### Cards & Case Study Showcases
- Glassmorphic panels with `1.5rem` padding and roundedness `2`.
- Includes a subtle top border gradient highlight (`linear-gradient(90deg, rgba(0,229,255,0.4), rgba(59,130,246,0.1), transparent)`).
- Project media containers use inner glass borders to contain interactive web app previews, terminal simulations, or schema diagrams.

### Input Fields & Terminal Contact
- Dark recessed inputs: background `rgba(11, 15, 23, 0.8)`, border `1px solid rgba(255, 255, 255, 0.12)`.
- Active focus state: border glows `#00E5FF` with `0 0 0 3px rgba(0, 229, 255, 0.15)`.
- Optional terminal prompt prefixes (`user@kashif:~$`) styled in JetBrains Mono muted cyan.

### Checkboxes & Segmented Controls
- Minimal switchers for filtering tech stacks (e.g., "All", "Full Stack", "Distributed Systems", "Cloud/DevOps").
- Active tab uses subtle glass background with crisp `#00E5FF` active indicator bar underneath.
